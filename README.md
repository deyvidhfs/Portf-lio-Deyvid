# Portfólio — Deyvid Henrique de Freitas Santos

Quatro projetos que transformam situações reais do meu trabalho em pequenas aplicações que rodam no navegador (HTML, CSS e JavaScript, sem backend).

| Projeto | Pasta | O que mostra |
|---|---|---|
| Loja de óculos com configurador | `oculos/` | Formulários, cálculo de preço, validações, medição de DNP por foto |
| Controle de estoque | `estoque/` | Regras de negócio, histórico de movimentações, exportação CSV |
| Painel de chamados e sinistros | `chamados/` | Fluxo de atendimento, prazos por prioridade, filtros |
| Orçamento e faturamento B2B | `orcamento/` | Cálculos, parcelas e vencimentos, status, impressão em PDF |

## Como ver
Abra o endereço do GitHub Pages deste repositório, ou abra `index.html` no navegador.

## Observações
- Todos os dados são fictícios.
- Os dados digitados ficam apenas no navegador (localStorage) e não são enviados a nenhum servidor.
- As ideias e regras de negócio são minhas; o código foi desenvolvido com apoio de inteligência artificial.
